# Beyond 100｜超越百岁

> 长寿，不只是把时间延长，而是在更长的人生里，继续拥有力量、选择和生活的余量。

《超越百岁》是 DOIT 持续建设的运动科学与长期健康知识库。

我们关注如何看懂身体的底层逻辑，减少高投入、低回报的身体维护与无效训练，在年龄增长中保留力量、活动能力、恢复力和生活自主性。

这里不贩卖“逆龄”承诺，也不把复杂问题压成一个姿势、一个动作或一种产品。我们从运动科学与健康管理出发，把复杂证据翻译成普通人能读懂、能判断、能行动的内容。

## DOIT 的两张地图

DOIT 用两套互相配合、但不能混为一谈的框架：

- **结构 → 功能 → 节律**：用于读懂身体，观察排列条件、真实表现和随时间变化的状态。
- **红旗 → 呼吸 → 地基 → 动作 → 负荷与恢复 → 复盘**：用于决定下一步，先确认边界，再选择训练入口。

一张静态照片只能呈现一个瞬间；一次自测只能提供观察线索。我们更关心现象是否反复出现、条件改变后是否变化、是否影响功能，以及身体能否从训练中恢复。

## 我们怎样做内容

**专业，但不堆论文。** 证据用于帮助判断，不用于制造权威感。

**易懂，但不牺牲准确。** 我们会用生活场景和适量类比解释复杂机制，同时分清相关、因果、机制推测和真实结果。

**能行动，但不越过边界。** 每篇尽量给出清楚的观察方法和下一步；通用建议不能替代个体评估。

**持续更新，但不换题套模板。** 每个主题独立展开，避免重复结构、重复金句和换汤不换药。
