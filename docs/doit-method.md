# DOIT 方法：先读懂身体，再决定怎么练

DOIT 关注的，不只是一个动作做得像不像，也不只是某块肌肉够不够强。

我们更关心：身体为什么会用现在的方式完成动作，以及怎样用更安全、可恢复、能长期积累的方式，让它重新变得可靠。

## 两张不同的地图

### 结构 → 功能 → 节律：用来读懂身体

这是观察身体的三个维度，不是简单的先后因果。

**结构**，是身体当下的排列与连接条件，包括关节位置、骨骼关系、足底支撑、骨盆与胸廓的相对位置，以及力量如何传递。

**功能**，是身体在真实任务中的表现，包括活动度、稳定性、力量、协调、平衡，以及走、蹲、推、拉、转身时采用的策略。

**节律**，是身体在时间中的状态，包括呼吸、神经紧张程度、疲劳、睡眠、恢复速度和训练后的反应。

同一个动作今天顺、明天不顺，未必是结构突然改变，也可能是疲劳和恢复状态不同。所以，一张静态照片只能让我们看见某个瞬间，不能直接说明全部原因。

### 红旗 → 呼吸 → 地基 → 动作 → 负荷与恢复 → 复盘：用来决定下一步

这是判断和行动的顺序。

- **结构、功能、节律**，是读身体时使用的观察地图。
- **红旗、呼吸、地基、动作、负荷与恢复、复盘**，是作出训练决策时使用的路线图。

## DOIT 的判断顺序

### 0｜红旗：先确认是否适合进入训练判断

如果存在急性损伤、持续加重的疼痛、麻木、放射痛、明显无力、夜间痛、发热或医生限制，应先接受医疗或线下专业评估。

训练不能代替诊断。

### 1｜呼吸：看身体是否处在可调节状态

呼吸影响胸廓活动、腹内压、颈肩代偿和动作节奏，也能提供身体紧张程度的线索。

先看呼吸，不代表所有问题都由呼吸造成。如果它并不是主要限制，就继续向下判断。

### 2｜地基：确认有没有稳定支撑

这里的“地基”不只指脚。

它包括足踝支撑、骨盆位置、躯干控制、本体感觉，以及髋部参与动作的能力。地基不稳定时，身体往往会在膝、腰、肩颈等位置寻找额外支撑。

### 3｜动作：观察身体如何完成任务

我们不只比较姿势外形，而是观察动作中的重心、力线、节奏、关节配合和代偿策略。

动作没有唯一模板。身体比例、任务目标和负荷不同，合理的动作外形也可能不同。

### 4｜负荷与恢复：判断剂量是否超过当前能力

动作本身未必有问题，问题也可能来自次数、重量、频率、速度或恢复不足。

训练刺激和恢复能力必须一起看。DOIT 所说的“零负担”，不是不训练，而是不制造无法恢复的消耗。

### 5｜复盘：用身体反应校正下一步

复盘关注训练中和训练后的真实反馈：

1. 动作是否更稳定；
2. 疼痛或不适是否出现；
3. 第二天能否恢复；
4. 日常活动是否更轻松；
5. 当前负荷是否值得继续。

训练不是一次性答案，而是不断观察、调整和积累的过程。

## 这套方法坚持什么

1. **不拿一个姿势替代完整判断。** 看见差异，不等于找到原因。
2. **不拿一个动作解决所有问题。** 同样的现象，背后可能是不同的限制。
3. **不把训练当作惩罚。** 真正有效的训练，应当能够恢复、能够进阶，也能够进入生活。

DOIT 希望建立的，不是一套让人依赖的标准答案，而是一种更清楚地理解身体、判断优先级和长期管理自己的能力。

> 说明：本文为运动与健康管理经验分享，不替代医疗诊断；如有明确伤病或持续疼痛，请先就医评估。
