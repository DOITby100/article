# 阅读指南：怎样使用这座运动科学知识库

这座知识库写给希望看懂身体、减少无效训练，并愿意长期管理运动能力的人。

你不需要先掌握解剖学或运动科学术语。每个主题都会尽量回答三个实际问题：

1. 我现在看到的现象，可能意味着什么？
2. 哪些信息对判断真正有用？
3. 我可以安全地做什么，什么时候应该停止？

## 时间有限时，先读这三部分

### 1｜核心判断

先弄清文章想纠正什么误区，以及最重要的结论是什么。不要只凭标题判断自己的身体。

### 2｜观察方法

文章中的自测和动作对照，只用于收集线索。它们可以帮助你看见差异，但不能替代诊断，也不能单独证明病因。

### 3｜行动与边界

重点看建议适合谁、应该从哪里开始，以及出现什么情况需要停止或寻求专业评估。

## 不要把文章当成统一处方

相似的外形，不一定来自相同原因。

同一个人换了鞋、增加负荷、睡眠不足，或只是当天更疲劳，动作表现都可能改变。使用一篇文章时，建议先问：

- 这个现象是否在不同场景中反复出现？
- 它是否伴随疼痛、无力或功能变化？
- 调整条件后，动作是否发生变化？
- 身体在训练后能否正常恢复？

这些问题比单纯比较“标准姿势”更有价值。

## 内容层级

- [`knowledge/`](../knowledge/)：按主题组织的公开知识索引。
- [`platforms/`](../platforms/)：公众号及未来其他平台的成品版本。
- [`catalog/`](../catalog/)：供人和程序检索的文章、标签与素材清单。
- [`docs/`](./)：方法、证据、边界与收录规则。

平台版本会适应具体阅读场景，但核心事实和健康边界应当一致。

## 怎样使用分类标签

每篇内容会尽量保留几类标签：

- **观察维度**：结构、功能、节律；
- **判断阶段**：红旗、呼吸、地基、动作、负荷、恢复、复盘；
- **身体区域**：足踝、膝、髋与骨盆、脊柱、肩颈等；
- **动作任务**：站立、步行、深蹲、髋铰链、推、拉、旋转等；
- **能力要素**：力量、活动度、稳定、平衡、协调、心肺耐力等。

标签用于寻找相关知识，不用于给身体贴标签。

## 更新与勘误

运动科学会持续发展，同一问题也可能随着新证据而调整表述。

如果发现事实、数据、链接或表达存在问题，可以通过 Issue 提交勘误。我们更重视可核查的修正，而不是维护一篇文章“永远正确”的表面。

> 说明：本文为运动与健康管理经验分享，不替代医疗诊断；如有明确伤病或持续疼痛，请先就医评估。
