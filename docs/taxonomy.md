# 知识分类：怎样整理《超越百岁》的内容

这座知识库不按“一个部位对应一个动作”的方式堆放内容。

身体问题往往同时涉及支撑、动作、负荷和恢复，因此我们使用“一个主分类＋少量交叉标签”的方式整理知识。

## 主分类

1. **方法与判断**：DOIT 方法、健康红旗、观察与评估、负荷和复盘。
2. **身体区域**：头颈、肩与上肢、胸廓与脊柱、核心、骨盆与髋、膝、足踝、全身联动。
3. **动作模式**：站立、坐起、行走、跑步、上下楼、单腿支撑、深蹲、髋铰链、推、拉、旋转与搬提。
4. **运动能力**：力量、活动度、稳定、平衡、协调、本体感觉、速度、爆发力与心肺耐力。
5. **负荷与恢复**：重量、次数、频率、速度、疲劳、睡眠、压力、减量和回归训练。
6. **生活功能与长期健康**：久坐、工作场景、跌倒风险、力量保留、独立生活能力和长期健康管理。
7. **证据与常见误区**：研究阅读、相关与因果、姿势标准化、万能动作、热点和数据勘误。

每篇内容只选择一个主分类。其他关联通过标签连接，避免同一条目在多个目录里重复出现。

## 分类规则

- **一篇内容只有一个主问题。** 其余关联用标签连接。
- **标签服务于查找，不服务于堆砌。** 每篇只保留真正相关的标签。
- **不用姿势名称代替结论。** “骨盆前倾”“圆肩”“膝内扣”等可以是观察词，不能自动等同于疾病或单一病因。
- **平台变化，事实不漂移。** 表达形式可以变化，核心判断、证据边界和健康说明保持一致。
- **中文名称面向读者，稳定 ID 面向数据。** 机器可读定义见 [`catalog/taxonomy.json`](../catalog/taxonomy.json)。
