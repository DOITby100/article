# 微信公众号内容库

这里收录《超越百岁》的公众号终审成品：主文、公众号摘要、16:9 封面、2.35:1 封面和正文插图。

## 文件组织

每篇文章使用独立目录：

```text
YYYYMMDD_第NNN篇_短标题/
├── YYYYMMDD_第NNN篇_文章标题.md
├── YYYYMMDD_第NNN篇_文章标题_公众号摘要.md
├── YYYYMMDD_第NNN篇_文章标题_封面_16比9.jpg
├── YYYYMMDD_第NNN篇_文章标题_封面_235比100.jpg
└── YYYYMMDD_第NNN篇_文章标题_插图NN_图意.jpg
```

公开收录标准见 [公开收录规范](../../docs/collection-standard.md)。
